# BetterBMS

Feather / AltStore source for **BetterBMS** IPAs. This repository is IPA-only — no app source.

## Sideload with Feather

1. Open **Feather** → Sources → add:
   ```
   https://raw.githubusercontent.com/Talaxin/BetterBMS/main/apps.json
   ```
2. Install **BetterBMS**. Feather signs it with your certificate.
3. Or download the `.ipa` from [Releases](https://github.com/Talaxin/BetterBMS/releases) and import it.

## Bundle ID

`com.talaxin.betterbms`
