# BetterBMS

iOS app for **JBD / Xiaoxiang** BLE BMS boards (CyberCase and similar).

## Sideload with Feather

1. Open **Feather** → Sources → add source:
   ```
   https://raw.githubusercontent.com/Talaxin/BetterBMS/main/apps.json
   ```
2. Install **BetterBMS** from that source (Feather signs with your certificate).
3. Or download the `.ipa` from [Releases](https://github.com/Talaxin/BetterBMS/releases) and import it in Feather.

Source file: [`apps.json`](./apps.json) (AltStore-compatible).

## Bundle ID

`com.talaxin.XiaoXiangBMS` (unchanged so updates replace the same app).

## Status

IPA releases are published under [Releases](https://github.com/Talaxin/BetterBMS/releases). Until the first release is up, the source lists the app with no downloadable version yet.
